# 📖 คำศัพท์กลางของระบบ (Glossary)

> **ไฟล์นี้คือแหล่งเดียวของคำที่ผู้ใช้เห็น** — ชื่อเมนู, `meta.title` ใน `constants/nav.ts`,
> หัวข้อหน้า, ปุ่ม, ข้อความ `Swal`, หัวคอลัมน์ export, เอกสาร และ `docs/skills.md`
> ต้องใช้คำในไฟล์นี้
>
> **เพิ่มคำใหม่** = ต่อท้ายไฟล์นี้ใน PR เดียวกัน (ไม่ต้องรอ) · ถ้าพบว่าที่ไหนใช้คำนอกชุด
> ให้แก้ที่ UI ก่อน แล้วค่อยบันทึก — เอกสารนี้ต้องตรงกับของที่ผู้ใช้เห็นจริง ไม่ใช่ความตั้งใจ

## 1. คน · ห้อง · สิทธิ์

| คำที่ใช้ | ใช้เมื่อ | ในโค้ด | ห้ามใช้ |
|---|---|---|---|
| **ห้อง** / **ห้องเรียน** | พูดถึงพื้นที่ข้อมูลหนึ่งห้อง ("สลับห้อง", "เลือกห้องเรียน") | `rooms`, `room_id` | คลาส · กลุ่ม · server |
| **นักเรียน** | เรียก **คน** ในรายชื่อห้อง (ชื่อหน้า, หัวคอลัมน์, ปุ่ม, ประโยคทั่วไป) | แถวใน `students` (การเป็นสมาชิกของห้อง) | ผู้เรียน · ลูกค้า · สมาชิก (ดูข้อถัดไป) |
| **สมาชิก** | ใช้ได้เฉพาะ **วลีเรื่องสิทธิ์/การเข้าถึง** เช่น "เฉพาะสมาชิกของห้อง", "ต้องเป็นสมาชิกที่ใช้งานอยู่" — **ห้ามใช้เป็นชื่อหน้า/ปุ่ม/คอลัมน์** | `require_member` | — |
| **ผู้ใช้** | พูดถึง **บัญชี** ที่ล็อกอิน (Google/Discord), การตั้งค่าบัญชี | `users` | user (ในข้อความไทย) |
| **บทบาท** | ตำแหน่งในห้อง (หัวหน้าห้อง, เหรัญญิก, …) | `students.class_role` + `is_admin` | role (ในข้อความไทย) |
| **สิทธิ์** | สิ่งที่ทำได้ตาม permission | `students.permissions` (JSONB) เช่น `MANAGE_FINANCE` | สิทธิ · อำนาจ |
| **ผู้จัดการห้อง** | สมาชิกที่มีสิทธิ์ดูแลรายชื่อ/PII (`MANAGE_STUDENTS`, `VIEW_ALL_STUDENTS`, `is_admin`, super admin) — ใช้ในข้อความอธิบายสิทธิ์เท่านั้น | `MANAGER_PERMISSIONS` ใน `core/rbac.py` | แอดมิน (เมื่อหมายถึงหลายสิทธิ์) · ผู้ดูแลข้อมูล |
| **ยืนยันตัวตน** | การที่เจ้าตัวกดยืนยันว่าตนคือคนในรายชื่อของห้องนั้น → ระบบใช้ข้อมูลบัญชีกลางทับค่าที่ห้องกรอก | `students.identity_claimed`, `accept_invite` | ยืนยันบัญชี · consent |
| **คำเชิญยืนยันตัวตน** | การ์ดใน Lobby ที่แจ้งว่า "ห้องนี้มีชื่อคุณแล้ว" — ใช้ห้องได้ทันที ไม่บล็อก กดเพื่อ merge ข้อมูล | `list_my_invites`, `notify_student_invite` | คำเชิญเข้าร่วม (เมื่อหมายถึงการรอรับก่อนเข้า) |
| **ข้อมูลเฉพาะห้อง** | ค่าโปรไฟล์ที่ห้องนั้นบันทึกทับบัญชีกลาง (มีผลเฉพาะห้องนั้น) | `student_room_profiles`, view `v_student_profiles` | override (ในข้อความผู้ใช้) · ข้อมูลสำรอง |

> คนหนึ่งคนมี **บัญชีเดียว** (`users`) แต่เป็น **นักเรียนได้หลายห้อง** (หลายแถวใน `students`)
> ⇒ ข้อความที่พูดถึง "นักเรียน" ต้องมีบริบทห้องกำกับเสมอเมื่ออาจกำกวม

### ป้ายสถานะนักเรียน

| ค่าใน DB | คำไทย |
|---|---|
| `active` | **กำลังเรียน** |
| `pending` | **รออนุมัติ** |
| `inactive` | **พ้นสภาพ** |

> **`pending` ใช้เฉพาะ:** คำขอเข้าร่วมห้อง (self-join) และคำขออ้างสิทธิ์ชื่อ ghost
> ที่รอหัวหน้าห้องอนุมัติ — ครูเพิ่มนักเรียนแล้วแถวเป็น `active` ทันที (นโยบาย 2026-11-01)
>
> แหล่งอ้างอิง: `backend/services/student/constants.py` → `STATUS_LABELS` ·
> ฝั่ง Vue: `frontend/src/constants/statusLabels.ts` → `STUDENT_STATUS_LABELS`
> (`StudentList`, `StudentProfile`, `Lobby` ใช้ร่วมกัน — **ห้ามเขียนข้อความสถานะซ้ำในวิว**)
> เทสต์ `frontend/src/constants/__tests__/statusLabels.spec.ts` ล็อกคำชุดนี้ไว้

## 2. เนื้อหาของห้อง

| คำที่ใช้ | ความหมาย | ในโค้ด | ห้ามใช้ |
|---|---|---|---|
| **งาน** | สิ่งที่ต้องส่งภายในวันที่กำหนด (มี `due_date`) | `tasks` | การบ้าน · ภารกิจ · งานที่ต้องทำ |
| **โน้ต** | บันทึกประจำวันของห้อง (ไม่มีกำหนดส่ง) | `daily_notes` | บันทึก · โพสต์ · ประกาศ |
| **กิจกรรม** | กิจกรรมที่มีวัน/สถานะ/ผู้เข้าร่วม และเช็คชื่อได้ | `activities` + `activity_participants` | อีเวนต์ · event · งาน (สับสนกับ `tasks`) |
| **ประกาศ** | ข้อความที่ส่งถึง **ทุกคนในห้อง** — ขึ้นในแอป แจ้งเตือนบนมือถือ และ Discord (ถ้าเชื่อมต่อ) | `announcements` + `announcement_service` (หนึ่งครั้ง → in-app + push + Discord) | ข้อความ · ข่าว · แจ้งข่าว |
| **ประกาศด่วน** | ประกาศระดับ `urgent` — แจ้งเตือนได้แม้อยู่ในช่วงงดรบกวน และ @ทุกคนใน Discord | `announcements.priority = 'urgent'` | ประกาศฉุกเฉิน (ใช้ "ด่วน") |
| **ปักหมุด** | ตรึงประกาศไว้บนสุดของหน้าแรก | `announcements.pinned` | ปัก · ติดหมุด |
| **เก็บถาวร** | ซ่อนประกาศออกจากรายการปกติ แต่ยังเปิดดูย้อนหลังได้ | `announcements.archived_at` | ลบประกาศ (ไม่ใช่การลบ) |
| **แจ้งเตือน** | ข้อความอัตโนมัติถึง **คนหนึ่ง/เหตุการณ์หนึ่ง** (เช่น "มีงานใหม่") | `notifications` + SSE + Web Push | ประกาศ |
| **ช่วงงดรบกวน** | เวลาที่ห้องกำหนดว่าไม่ส่ง push (ยกเว้นประกาศด่วน) — ตั้งได้ที่หน้าตั้งค่าของห้อง | `app_settings.quiet_hours` (`services/app_settings_service.py`) | ห้ามรบกวน · Do Not Disturb · quiet hours (ในข้อความผู้ใช้) |
| **ของฉัน** | ไทม์ไลน์ส่วนตัว (ใบเสร็จที่ออกให้ฉัน · กิจกรรมที่ฉันเข้าร่วม) + สถิติ + รายการที่บันทึกไว้ | `views/me/MyActivity.vue`, `/api/classroom/{id}/me/*` | โปรไฟล์นักเรียน (คนละหน้า) · ฟีด · feed |
| **บันทึกไว้** | บุ๊กมาร์กรายคนของประกาศ/กิจกรรมที่อยากกลับมาอ่าน (ของคน ไม่ใช่ของห้อง) | `bookmarks`, `/api/classroom/{id}/bookmarks` | เซฟ · favorite · รายการโปรด |
| **เช็คอิน** | ยืนยันว่า "มาแล้ว" ณ งานจริง (กดในลิสต์) → `status='attended'` + เวลา + ชื่อคนกด | `activity_participants.checked_in_at` / `checked_in_by` (NULL = แถว `attended` ยุคก่อน P4.2 หรือยังไม่เคยเช็คอิน) | ลงชื่อ (แผ่นเช็คชื่อคือของอีกอย่าง) · check-in (ในข้อความผู้ใช้) |
| **หมวดกิจกรรม** | ประเภทของกิจกรรม จากรายการปิดตายตัว (ค่าย · การแข่งขัน · จิตอาสา · อบรม/สัมมนา · พิธีการ · อื่น ๆ) | `activities.category` (`ACTIVITY_CATEGORIES` ใน `services/activity/constants.py` ↔ `frontend/src/constants/activityCategories.ts`) | ประเภทกิจกรรม · แท็ก · หมวดหมู่ (คำนี้เป็นของการเงิน) |
| **ตารางเรียน** | ตารางเรียนประจำสัปดาห์ + การแก้เฉพาะสัปดาห์ | `default_schedules`, `schedule_overrides` | ตารางสอน · ตารางเวลา |
| **แผนผังห้องเรียน** | ผังบทบาท/โครงสร้างห้อง (หัวหน้า–รอง–กรรมการ) | `views/roadmap/RoadmapView.vue` | org chart · ผังองค์กร |

### ป้ายสถานะงาน

| ค่าใน DB | คำไทย |
|---|---|
| `pending` | **ยังไม่เสร็จ** |
| `done` | **เสร็จแล้ว** |

> ฝั่ง Vue: `frontend/src/constants/statusLabels.ts` → `TASK_STATUS_LABELS` (`TaskList` ใช้)
> — ส่วน "ส่งวันนี้ / ส่งพรุ่งนี้ / เลยกำหนดมา N วัน" เป็น **คำอธิบายกำหนดส่ง** ไม่ใช่ป้ายสถานะ
> จึงคงรูปเดิมได้

## 3. การเงิน

| คำที่ใช้ | ความหมาย | ในโค้ด | ห้ามใช้ |
|---|---|---|---|
| **การเงิน** | โมดูลทั้งหมด (เมนู, ชื่อหน้า) | `/finance/*` | การบัญชี · ไฟแนนซ์ |
| **ผู้เกี่ยวข้องทางการเงิน** | ทะเบียนคนที่รับเงิน/จ่ายเงิน/อนุมัติของห้อง (ครู · นักเรียน · บุคคลภายนอก) — เลือกจากทะเบียนนี้เสมอ ไม่พิมพ์ชื่ออิสระในเอกสาร | `finance_people`, `/finance/people` | ผู้รับเงิน (เมื่อหมายถึงทะเบียนทั้งกลุ่ม) · payee · contact |
| **บทบาทผู้เกี่ยวข้อง** | สิ่งที่คนในทะเบียนทำได้: **ผู้รับเงิน** (`receive`) · **ผู้จ่าย** (`pay`) · **ผู้อนุมัติ** (`approve`) — หนึ่งคนมีได้หลายบทบาท | `finance_people.roles` | role (ในข้อความไทย) |
| **ค่าเริ่มต้นการรับเงิน** | ผู้รับเงิน/กระเป๋าเงิน/ข้อความท้ายใบเสร็จ ที่ฟอร์มรับเงินเติมให้ก่อน (เปลี่ยนรายครั้งได้) | `finance_settings`, `/finance/settings` | default · ตั้งค่าทั่วไป |
| **รายรับ** / **รายจ่าย** | เงินเข้า / เงินออกของห้อง | `finance_transactions` (`type`) | รายได้ · รายจ่าย (เขียน "รายจ่าย" ให้ถูก) |
| **บัญชี** | บัญชีเงินสด/ธนาคารที่ผูกกับห้อง | `finance_accounts` | account (ในข้อความไทย) |
| **หมวดหมู่** | ประเภทของรายรับ/รายจ่าย | `finance_categories` | หมวด · category |
| **โปรเจกต์เก็บเงิน** | แคมเปญที่เก็บเงินจากนักเรียนหลายคน | `fee_collections` | คอลเลกชัน · แคมเปญ · collection |
| **บิล / งวด** | หนึ่งรายการที่นักเรียนต้องจ่ายในโปรเจกต์ | `student_payments` | invoice (สำหรับงวด) · ใบวางบิล |
| **ผู้ค้างชำระ** | นักเรียนที่ยังไม่จ่ายครบ | `/finance/debtors` | ลูกหนี้ · debtor |
| **เงินรับล่วงหน้า** | เงินที่นักเรียนจ่ายเก็บไว้ก่อน (เครดิต) | `student_credits` | เครดิต · credit |
| **บัญชีรายบุคคล** | หน้าเดียวที่รวมยอดค้าง · เกินกำหนด · เครดิตของนักเรียนแต่ละคน (แทนการเปิดสองหน้าคู่กัน `ผู้ค้างชำระ` + `เงินรับล่วงหน้า`) — อ่านอย่างเดียว สมาชิกห้องเข้าถึงได้ | `/finance/individual-accounts`, `IndividualAccountsMixin` | บัญชีนักเรียน · ลูกหนี้รายคน · account |
| **รายการเดินบัญชี** | ลำดับบิล/รับเงิน/เครดิตของนักเรียนคนหนึ่งตามช่วงวันที่ (เก่า→ใหม่) พร้อมยอดเครดิตคงเหลือหลังรายการ | `/finance/individual-accounts/:id/statement`, `get_student_statement` | statement (เมื่อหมายถึงหน้าของนักเรียน) · ใบแจ้งรายการ |
| **รายการรับเงิน** | เหตุการณ์รับเงินของนักเรียน 1 คน 1 ครั้ง — ปิดได้หลายบิล · ใช้เครดิต · เก็บส่วนเกินเป็นเครดิต และออก **ใบเสร็จ 1 ใบที่มีหลายรายการย่อย** (ไม่ใช่ 1 ใบต่อบิลแบบเดิม) | `finance_payment_events`, `finance_payment_event_lines`, `/finance/payment-events` | event (ในข้อความไทย) · ใบเสร็จแยกต่อบิล |
| **ผู้ชำระเงิน** | คนที่นำเงินมาชำระในรายการรับเงิน — เติมชื่อนักเรียนเป็นค่าเริ่มต้น แก้เป็นชื่อผู้ปกครองได้ | `finance_payment_events.payer_name` | payee · ผู้จ่าย (เมื่อหมายถึงคนที่ห้องจ่ายเงินให้) |
| **ชื่อเต็มบนเอกสาร** | ชื่อที่พิมพ์บนบิล/เอกสารการเงิน = **คำนำหน้า + ชื่อ + นามสกุล** (ไทยก่อน; ไม่มีชื่อไทยค่อยใช้ชื่ออังกฤษ) — **ไม่ต่อชื่อเล่นในวงเล็บ** แม้หน้าจออื่นจะใช้ชื่อเล่น | `_full_name()` (`services/finance/helpers.py`) · `displayName()` (`frontend/src/utils/name.ts`) | ชื่อ(ชื่อเล่น) · nickname |

## 4. วัน · เวลา · ตัวเลข

- **ปีการศึกษา** แสดงเป็น **พ.ศ.** เสมอ (`year_be`) — 2026 = 2569 · ค.ศ. ใช้เฉพาะในโค้ด/log
- **เทอม** ใช้คำว่า "เทอม" (เทอม 1 / เทอม 2) **ไม่ใช่ "ภาคเรียน"** — เป็นช่วงย่อยในปีการศึกษาของห้อง
  และใช้ **กรองสถิติเท่านั้น** ไม่ได้ย้ายนักเรียนขึ้นชั้น (ดู `docs/skills.md` หัวข้อ P5)
- **วันที่** เขียนไทยเต็ม เช่น `24 ตุลาคม 2569` (ไม่ใช้ `24/10/69`)
- **เวลา** `HH:mm` 24 ชั่วโมง · โซนเวลา `Asia/Bangkok` (UTC+7) ทุกจุดที่แสดงหรือเก็บ "เวลาที่ผู้ใช้เป็นหลักฐาน"
- **เงิน** ทศนิยม 2 ตำแหน่ง + คั่นหลักพัน (`1,250.00 บาท`) — ฝั่ง Vue ใช้ `utils/money.ts` อย่าจัดรูปเองในวิว
