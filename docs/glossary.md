## 1. คน · ห้อง · สิทธิ์

| คำที่ใช้ | ใช้เมื่อ | ในโค้ด | ห้ามใช้ |
|---|---|---|---|
| **ห้อง** / **ห้องเรียน** | พูดถึงพื้นที่ข้อมูลหนึ่งห้อง ("สลับห้อง", "เลือกห้องเรียน") | `rooms`, `room_id` | คลาส · กลุ่ม · server |
| **นักเรียน** | เรียก **คน** ในรายชื่อห้อง (ชื่อหน้า, หัวคอลัมน์, ปุ่ม, ประโยคทั่วไป) | แถวใน `students` (การเป็นสมาชิกของห้อง) | ผู้เรียน · ลูกค้า · สมาชิก (ดูข้อถัดไป) |
| **สมาชิก** | ใช้ได้เฉพาะ **วลีเรื่องสิทธิ์/การเข้าถึง** เช่น "เฉพาะสมาชิกของห้อง", "ต้องเป็นสมาชิกที่ใช้งานอยู่" — **ห้ามใช้เป็นชื่อหน้า/ปุ่ม/คอลัมน์** | `require_member` | — |
| **ผู้ใช้** | พูดถึง **บัญชี** ที่ล็อกอิน (Google/Discord), การตั้งค่าบัญชี | `users` | user (ในข้อความไทย) |
| **บทบาท** | ตำแหน่งในห้อง (หัวหน้าห้อง, เหรัญญิก, …) | `students.class_role` + `is_admin` | role (ในข้อความไทย) |
| **สิทธิ์** | สิ่งที่ทำได้ตาม permission | `students.permissions` (JSONB) เช่น `MANAGE_FINANCE` | สิทธิ · อำนาจ |
| **ผู้จัดการห้อง** | สมาชิกที่มีสิทธิ์ดูแลรายชื่อ/PII (`MANAGE_STUDENTS`, `VIEW_ALL_STUDENTS`, `is_admin`, super admin) — ใช้ในข้อความอธิบายสิทธิ์เท่านั้น | `MANAGER_PERMISSIONS` ใน `core/rbac.py` | แอดมิน (เมื่อหมายถึงหลายสิทธิ์) · ผู้ดูแลข้อมูล |
| **ยืนยันตัวตน** | การที่เจ้าตัวกดยืนยันว่าตนคือคนในรายชื่อของห้องนั้น → ระบบใช้ข้อมูลบัญชีกลางทับค่าที่ห้องกรอก | `students.identity_claimed`, `accept_invite` | ยืนยันบัญชี · consent |
| **คำเชิญยืนยันตัวตน** | การ์ดใน Lobby ที่แจ้งว่า "ห้องนี้มีชื่อคุณแล้ว" — ใช้ห้องได้ทันที ไม่บล็อก กดเพื่อ merge ข้อมูล | `list_my_invites`, `notify_student_invite` | คำเชิญเข้าร่วม (เมื่อหมายถึงการรอรับก่อนเข้า) |
| **ข้อมูลเฉพาะห้อง** | ค่าโปรไฟล์ที่ห้องนั้นบันทึกทับบัญชีกลาง (มีผลเฉพาะห้องนั้น) | `student_room_profiles`, view `v_student_profiles` | override (ในข้อความผู้ใช้) · ข้อมูลสำรอง |

> คนหนึ่งคนมี **บัญชีเดียว** (`users`) แต่เป็น **นักเรียนได้หลายห้อง** (หลายแถวใน `students`)
> ⇒ ข้อความที่พูดถึง "นักเรียน" ต้องมีบริบทห้องกำกับเสมอเมื่ออาจกำกวม

### ป้ายสถานะนักเรียน

| ค่าใน DB | คำไทย |
|---|---|
| `active` | **กำลังเรียน** |
| `pending` | **รออนุมัติ** |
| `inactive` | **พ้นสภาพ** |

> **`pending` ใช้เฉพาะ:** คำขอเข้าร่วมห้อง (self-join) และคำขออ้างสิทธิ์ชื่อ ghost
> ที่รอหัวหน้าห้องอนุมัติ — ครูเพิ่มนักเรียนแล้วแถวเป็น `active` ทันที (นโยบาย 2026-11-01)
>
> แหล่งอ้างอิง: `backend/services/student/constants.py` → `STATUS_LABELS` ·
> ฝั่ง Vue: `frontend/src/constants/statusLabels.ts` → `STUDENT_STATUS_LABELS`
> (`StudentList`, `StudentProfile`, `Lobby` ใช้ร่วมกัน — **ห้ามเขียนข้อความสถานะซ้ำในวิว**)
> เทสต์ `frontend/src/constants/__tests__/statusLabels.spec.ts` ล็อกคำชุดนี้ไว้

## 4. วัน · เวลา · ตัวเลข

- **ปีการศึกษา** แสดงเป็น **พ.ศ.** เสมอ (`year_be`) — 2026 = 2569 · ค.ศ. ใช้เฉพาะในโค้ด/log
- **เทอม** ใช้คำว่า "เทอม" (เทอม 1 / เทอม 2) **ไม่ใช่ "ภาคเรียน"** — เป็นช่วงย่อยในปีการศึกษาของห้อง
  และใช้ **กรองสถิติเท่านั้น** ไม่ได้ย้ายนักเรียนขึ้นชั้น (ดู `docs/skills.md` หัวข้อ P5)
- **วันที่** เขียนไทยเต็ม เช่น `24 ตุลาคม 2569` (ไม่ใช้ `24/10/69`)
- **เวลา** `HH:mm` 24 ชั่วโมง · โซนเวลา `Asia/Bangkok` (UTC+7) ทุกจุดที่แสดงหรือเก็บ "เวลาที่ผู้ใช้เป็นหลักฐาน"
- **เงิน** ทศนิยม 2 ตำแหน่ง + คั่นหลักพัน (`1,250.00 บาท`) — ฝั่ง Vue ใช้ `utils/money.ts` อย่าจัดรูปเองในวิว

## 5. ตารางแปลงคำ (สำหรับเขียนโค้ด)

| ไทย | โค้ด / route |
|---|---|
| ห้อง | `room`, `room_id` |
| นักเรียน | `student` (แถว `students`) |
| ผู้ใช้ | `user` (แถว `users`) |
| งาน | `task` |
| โน้ต | `daily_note` |
| กิจกรรม | `activity` · ผู้เข้าร่วม = `participant` |
| หมวดกิจกรรม | `category` (ค่า: `camp` / `competition` / `volunteer` / `training` / `ceremony` / `other`) |
| ปีการศึกษา | `academic_year` (ตาราง `academic_years`) · ปีปัจจุบัน = `is_current` |
| เทอม | `academic_term` (ตาราง `academic_terms`) · ทั้งคู่ใช้กรองสถิติ ไม่ผูกกับแถว `students` |
| ประกาศ | `announcement` (ตาราง `announcements`) — หน้า UI เรียก "ประกาศ" |
| แจ้งเตือน | `notification` (ตาราง `notifications`) — สร้างโดย trigger fan-out |
| ยังไม่อ่าน | `is_unread` ของประกาศ = มีแถว `notifications.read_at IS NULL` ของผู้ใช้คนนั้น |
| บันทึกกิจกรรม | `audit_log` (ตาราง `audit_logs`) — หน้า `views/settings/AuditLogs.vue`, สิทธิ์ `VIEW_AUDIT_LOGS` · **ห้ามเรียก "log" / "ประวัติระบบ" ในข้อความผู้ใช้** |
| ช่วงงดรบกวน | `app_settings` ที่คีย์ `quiet_hours` (`QUIET_HOURS_KEY`) |
| รายรับ/รายจ่าย | `income` / `expense` (ใน `finance_transactions.type`) |
