# 📖 คำศัพท์กลางของระบบ (Glossary)

> **ไฟล์นี้คือแหล่งเดียวของคำที่ผู้ใช้เห็น** — ชื่อเมนู, `meta.title` ใน `constants/nav.ts`,
> หัวข้อหน้า, ปุ่ม, ข้อความ `Swal`, หัวคอลัมน์ export, เอกสาร และ `docs/skills.md`
> ต้องใช้คำในไฟล์นี้
>
> **เพิ่มคำใหม่** = ต่อท้ายไฟล์นี้ใน PR เดียวกัน (ไม่ต้องรอ) · ถ้าพบว่าที่ไหนใช้คำนอกชุด
> ให้แก้ที่ UI ก่อน แล้วค่อยบันทึก — เอกสารนี้ต้องตรงกับของที่ผู้ใช้เห็นจริง ไม่ใช่ความตั้งใจ

## 1. คน · ห้อง · สิทธิ์

| คำที่ใช้ | ใช้เมื่อ | ในโค้ด | ห้ามใช้ |
|---|---|---|---|
| **ห้อง** / **ห้องเรียน** | พูดถึงพื้นที่ข้อมูลหนึ่งห้อง ("สลับห้อง", "เลือกห้องเรียน") | `rooms`, `room_id` | คลาส · กลุ่ม · server |
| **นักเรียน** | เรียก **คน** ในรายชื่อห้อง (ชื่อหน้า, หัวคอลัมน์, ปุ่ม, ประโยคทั่วไป) | แถวใน `students` (การเป็นสมาชิกของห้อง) | ผู้เรียน · ลูกค้า · สมาชิก (ดูข้อถัดไป) |
| **สมาชิก** | ใช้ได้เฉพาะ **วลีเรื่องสิทธิ์/การเข้าถึง** เช่น "เฉพาะสมาชิกของห้อง", "ต้องเป็นสมาชิกที่ใช้งานอยู่" — **ห้ามใช้เป็นชื่อหน้า/ปุ่ม/คอลัมน์** | `require_member` | — |
| **ผู้ใช้** | พูดถึง **บัญชี** ที่ล็อกอิน (Google/Discord), การตั้งค่าบัญชี | `users` | user (ในข้อความไทย) |
| **บทบาท** | ตำแหน่งในห้อง (หัวหน้าห้อง, เหรัญญิก, …) | `students.class_role` + `is_admin` | role (ในข้อความไทย) |
| **สิทธิ์** | สิ่งที่ทำได้ตาม permission | `students.permissions` (JSONB) เช่น `MANAGE_FINANCE` | สิทธิ · อำนาจ |

> คนหนึ่งคนมี **บัญชีเดียว** (`users`) แต่เป็น **นักเรียนได้หลายห้อง** (หลายแถวใน `students`)
> ⇒ ข้อความที่พูดถึง "นักเรียน" ต้องมีบริบทห้องกำกับเสมอเมื่ออาจกำกวม

### ป้ายสถานะนักเรียน

| ค่าใน DB | คำไทย |
|---|---|
| `active` | **กำลังเรียน** |
| `pending` | **รออนุมัติ** |
| `inactive` | **พ้นสภาพ** |

> แหล่งอ้างอิง: `backend/services/student/constants.py` → `STATUS_LABELS` ·
> ฝั่ง Vue: `frontend/src/constants/statusLabels.ts` → `STUDENT_STATUS_LABELS`
> (`StudentList`, `StudentProfile`, `Lobby` ใช้ร่วมกัน — **ห้ามเขียนข้อความสถานะซ้ำในวิว**)
> เทสต์ `frontend/src/constants/__tests__/statusLabels.spec.ts` ล็อกคำชุดนี้ไว้

## 2. เนื้อหาของห้อง

| คำที่ใช้ | ความหมาย | ในโค้ด | ห้ามใช้ |
|---|---|---|---|
| **งาน** | สิ่งที่ต้องส่งภายในวันที่กำหนด (มี `due_date`) | `tasks` | การบ้าน · ภารกิจ · งานที่ต้องทำ |
| **โน้ต** | บันทึกประจำวันของห้อง (ไม่มีกำหนดส่ง) | `daily_notes` | บันทึก · โพสต์ · ประกาศ |
| **กิจกรรม** | กิจกรรมที่มีวัน/สถานะ/ผู้เข้าร่วม และเช็คชื่อได้ | `activities` + `activity_participants` | อีเวนต์ · event · งาน (สับสนกับ `tasks`) |
| **ประกาศ** | ข้อความที่ส่งถึง **ทุกคนในห้อง** (วันนี้ช่องทางเดียว = Discord ที่หน้า `/messages`) | `ActionService.notify_custom_message` (P2 จะมี in-app + push) | ข้อความ · ข่าว · แจ้งข่าว |
| **แจ้งเตือน** | ข้อความอัตโนมัติถึง **คนหนึ่ง/เหตุการณ์หนึ่ง** (เช่น "มีงานใหม่") | ช่องแจ้งเตือนใน Discord ผ่าน `ActionService` (P2: in-app/push) | ประกาศ |
| **ตารางเรียน** | ตารางเรียนประจำสัปดาห์ + การแก้เฉพาะสัปดาห์ | `default_schedules`, `schedule_overrides` | ตารางสอน · ตารางเวลา |
| **แผนผังห้องเรียน** | ผังบทบาท/โครงสร้างห้อง (หัวหน้า–รอง–กรรมการ) | `views/roadmap/RoadmapView.vue` | org chart · ผังองค์กร |

## 3. การเงิน

| คำที่ใช้ | ความหมาย | ในโค้ด | ห้ามใช้ |
|---|---|---|---|
| **การเงิน** | โมดูลทั้งหมด (เมนู, ชื่อหน้า) | `/finance/*` | การบัญชี · ไฟแนนซ์ |
| **รายรับ** / **รายจ่าย** | เงินเข้า / เงินออกของห้อง | `finance_transactions` (`type`) | รายได้ · รายจ่าย (เขียน "รายจ่าย" ให้ถูก) |
| **บัญชี** | บัญชีเงินสด/ธนาคารที่ผูกกับห้อง | `finance_accounts` | account (ในข้อความไทย) |
| **หมวดหมู่** | ประเภทของรายรับ/รายจ่าย | `finance_categories` | หมวด · category |
| **โปรเจกต์เก็บเงิน** | แคมเปญที่เก็บเงินจากนักเรียนหลายคน | `fee_collections` | คอลเลกชัน · แคมเปญ · collection |
| **บิล / งวด** | หนึ่งรายการที่นักเรียนต้องจ่ายในโปรเจกต์ | `student_payments` | invoice (สำหรับงวด) · ใบวางบิล |
| **ผู้ค้างชำระ** | นักเรียนที่ยังไม่จ่ายครบ | `/finance/debtors` | ลูกหนี้ · debtor |
| **เงินรับล่วงหน้า** | เงินที่นักเรียนจ่ายเก็บไว้ก่อน (เครดิต) | `student_credits` | เครดิต · credit |
| **งบประมาณ** | วงเงินที่ตั้งไว้ต่อหมวด | `finance_budgets` | budget |
| **งบการเงิน** | รายงานสรุปฐานะ (รายรับ–รายจ่าย) | `/finance/statements` | ใบงบ · statement |

### เอกสารการเงิน — `finance_receipts.doc_type`

| `doc_type` | คำเต็ม (บนกระดาษ/API) | เลขที่ | ใช้เมื่อ |
|---|---|---|---|
| `receipt` | **ใบเสร็จรับเงิน** | `REC-2569-0042` | รับเงินจากบิล/โปรเจกต์ |
| `invoice` | **ใบแจ้งหนี้** | `INV-2569-0012` | เรียกเก็บเงินล่วงหน้า |
| `deposit` | **ใบรับเงินล่วงหน้า** | `DEP-2569-0003` | รับเงินเก็บไว้ก่อน |
| `payment_voucher` | **ใบสำคัญจ่าย** | `PV-2569-0007` | ห้องจ่ายเงินออก |
| `income` | **ใบรับเงิน** | `INC-2569-0011` | รับเงินเข้าที่ไม่ได้มาจากบิลของนักเรียน |

> แหล่งอ้างอิง: `backend/services/finance/constants.py` → `DOC_TYPE_LABELS`, `DOC_TYPE_PREFIXES`
> (ทั้งสองตารางต้องแก้คู่กัน และ `RECEIPT_LIKE_DOC_TYPES` เป็นตัวตัดสินถ้อยคำบนกระดาษ)
>
> ในเมนู/หัวข้อหน้าใช้คำสั้น **"ใบเสร็จ"** ได้ แต่ทะเบียนเดียวมีทุกชนิดปนกัน ⇒
> ห้ามเรียกหน้า `/finance/receipts` ว่า "หน้าใบเสร็จ" เฉย ๆ (หัวหน้าใช้ "ใบเสร็จ / ใบแจ้งหนี้")

## 4. วัน · เวลา · ตัวเลข

- **ปีการศึกษา** แสดงเป็น **พ.ศ.** เสมอ (`year_be`) — 2026 = 2569 · ค.ศ. ใช้เฉพาะในโค้ด/log
- **วันที่** เขียนไทยเต็ม เช่น `24 ตุลาคม 2569` (ไม่ใช้ `24/10/69`)
- **เวลา** `HH:mm` 24 ชั่วโมง · โซนเวลา `Asia/Bangkok` (UTC+7) ทุกจุดที่แสดงหรือเก็บ "เวลาที่ผู้ใช้เป็นหลักฐาน"
- **เงิน** ทศนิยม 2 ตำแหน่ง + คั่นหลักพัน (`1,250.00 บาท`) — ฝั่ง Vue ใช้ `utils/money.ts` อย่าจัดรูปเองในวิว

## 5. ตารางแปลงคำ (สำหรับเขียนโค้ด)

| ไทย | โค้ด / route |
|---|---|
| ห้อง | `room`, `room_id` |
| นักเรียน | `student` (แถว `students`) |
| ผู้ใช้ | `user` (แถว `users`) |
| งาน | `task` |
| โน้ต | `daily_note` |
| กิจกรรม | `activity` · ผู้เข้าร่วม = `participant` |
| ประกาศ | `announcement` (P2) · วันนี้คือ `notify_custom_message` |
| แจ้งเตือน | `notification` (P2) |
| รายรับ/รายจ่าย | `income` / `expense` (ใน `finance_transactions.type`) |
| ใบเสร็จ / ใบแจ้งหนี้ / ใบรับเงินล่วงหน้า | `receipt` / `invoice` / `deposit` |
| ผู้ค้างชำระ | `debtor` |
| เงินรับล่วงหน้า | `credit` |
